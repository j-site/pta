## 「見やすさ」のための変更

- 本文を15px→**16px**、カード本文を13.5px→**15px**、注釈を13px→14pxに拡大
- 文字色のコントラストをWCAG AA（4.5:1）以上に調整
- 本文の1行あたりの文字数を制限（`max-width: 34em`）
- 長い説明文を、箇条書き・チップ・カードに分解
- ヒーローの抽象的なキャッチを見出しから外し、**何をする会社かを最初の1行**に。
  ブランドのスローガン（皆が表現できないものを、わたしたちが現実にする。）は
  引用として残しています

## 「頼みやすさ」のための変更

- **ハードルの低い相談例を8つ提示**（壁紙の剥がれ、蛇口の水漏れ等）。
  「これくらいで頼んでいいのか」という迷いを消すのが狙いです
- CTAの文言を「無料で相談する」→**「写真を送って無料見積り」**（次の行動が具体的）
- ボタンのすぐ下に**不安を消す一言**（相談・見積り無料／断ってOK／しつこい営業なし）
- **PCヘッダーに電話番号を常設**
- **スマホは画面下に「電話」「フォーム」を常時表示**（従来はハンバーガーを開かないとCTAに到達できなかった）
- 「費用について」セクションを新設
- よくあるご質問を新設（保険・断られた工事・見積りの断り方など7問）

## 書体について

| 用途 | 書体 |

当初の Noto Sans JP + Montserrat は、テンプレートや自動生成のサイトで最も多用される
組み合わせのため変更しました。見出しに明朝体を使うことで、同業他社のサイトとの差別化と
「職人・確かさ」の印象を狙っています。本文は可読性を優先してゴシックのままです。

書体を差し替える場合は、次の2箇所だけを変更してください。

1. ファイル冒頭の `<link href="https://fonts.googleapis.com/css2?family=...">`
2. CSS内の `--font-head` / `--font-jp` / `--font-en` の3行

## 火災保険まわりの方針

保険金請求のサポートは**消費者庁が注意喚起している分野**です。トラブルの多くは
「必ず保険金が下りる」という説明、成功報酬型の請求代行、そして解約時の違約金に
起因します。同じ土俵に見られないよう、ページは次のスタンスを軸に構成しています。

> 保険金を決めるのは保険会社。私たちの仕事は、正しい証拠を揃えること。

### ページに明記していること

| 項目 | 記載内容 |
| --- | --- |
| 判断主体 | 支払いを判断するのは保険会社。当社は認定を約束しない |
| 証拠のつくり方 | 現地調査／全景・中景・近景の3段階撮影とスケール併記／災害との関連の所見／復旧工事の積算、の4段階を具体的に提示 |
| 申請者 | 保険金請求は契約者の権利のため、申請はお客様のお名前で行う |
| 交渉の代理 | 行わない。不服がある場合はそんぽADRセンター等の公的窓口を案内 |
| 報酬 | 成功報酬なし・違約金なし。いただくのは工事代金のみ |
| 対象外 | 経年劣化・施工不良・故意過失・免責金額未満などを「対象になりにくい例」として明示 |
| 虚偽請求 | 事実と異なる内容の請求には一切関与しない |

### 「代行」という語を使っていない理由

保険金請求そのものは契約者の権利であり、保険会社との交渉を業として代理すると
弁護士法72条に触れうる領域です。「請求代行」を掲げる業者が行政の注意喚起対象に
なっているのもここです。

一方、**調査・被害写真・所見・修理見積書を作成することは建設会社の専門領域**そのもので、
何ら問題ありません。そこで役割を次のように切り分けて記載しています。

- 証拠書類の作成・現地調査への立会い → 当社
- 保険会社への申請 → お客様（ご契約者）
- 支払いの判断 → 保険会社

この切り分けは、法的リスクを避けるためであると同時に、保険会社・鑑定人から見ても
筋の通った相手として扱われるための設計です。「保険会社・鑑定人のみなさまへ」という
ブロックを設け、追加資料の要請に応じる姿勢と、虚偽請求に関与しない方針を明記しています。
