# 株式会社Crastore ホームページ（複数ページ版）

1ページに全部を書いていた構成をやめ、メニューで8ページに分けた構成です（2026年11月作り直し）。

## ページ一覧とWordPressでの作り方

各ページとも **固定ページを1つ作り、「カスタムHTML」ブロックに `site/dist/` のファイルを丸ごと貼り付けて公開** します。
URLスラッグはページ間のリンクと一致させる必要があるため、必ず下の表の通りにしてください。

| ページ | 貼り付けるファイル | URLスラッグ | 公開URL |
| --- | --- | --- | --- |
| ホーム | `wp-home.html` | （自由） | https://crastore.xyz/ ※設定→表示設定でホームページに指定 |
| 建築工事・リフォーム | `wp-building.html` | `building` | https://crastore.xyz/building/ |
| 火災保険を使った修繕 | `wp-fire-insurance.html` | `fire-insurance` | https://crastore.xyz/fire-insurance/ |
| 船の内装工事 | `wp-ship-interior.html` | `ship-interior` | https://crastore.xyz/ship-interior/ （既存ページを差し替え） |
| 錆止め | `wp-rust-proofing.html` | `rust-proofing` | https://crastore.xyz/rust-proofing/ |
| 室内の除菌・消臭 | `wp-deodorize.html` | `deodorize` | https://crastore.xyz/deodorize/ |
| 会社概要 | `wp-company.html` | `company` | https://crastore.xyz/company/ |
| お問い合わせ | `wp-contact.html` | `contact` | https://crastore.xyz/contact/ |

- 同じスラッグのページ（下書き・ゴミ箱を含む）が既にあると、WordPressが `building-2` のように番号を付けます。
  その場合は古いページを完全に削除してから付け直してください。
- 各ファイルの冒頭コメントに、検索結果用のタイトルと説明文を書いてあります。SEOプラグインがあれば設定してください。
- 「要確認」で検索すると、事実の確認・追記が必要な箇所が見つかります（対応エリア、錆止めの単価に含まれる範囲と根拠、
  船の種類・作業場所、除菌消臭の対応範囲、施工事例の写真）。

## 構成の考え方

- **ホームは「入口」に徹する**：ヒーロー → 相談内容から選ぶ（4事業＋火災保険）→ 頼む理由3つ → 流れ → 問い合わせ。
- **事業ごとに1ページ**：「錆止め 大阪」「船の内装工事」「火災保険 修理」など、検索される言葉ごとに専用ページがあるほうが
  検索に出やすく、来た人も迷いません。各ページの最後に「ほかの事業」へのリンクを置いています。
- **問い合わせの入口を3つ**：フォーム（staffpro.jp）・LINE・電話。スマホでは画面下に3つを常に表示します。
  お問い合わせページでは「何を送ればいいか」も案内し、最初の一通のハードルを下げています。

## ファイル構成と直し方

```
site/
  build.py          … 全ページを組み立てるスクリプト（ページ一覧・メニュー・タイトルもここ）
  src/base.css      … 全ページ共通のCSS
  src/script.js     … メニュー開閉・フェードインのJS
  src/pages/*.html  … 各ページの本文
  dist/wp-*.html    … WordPressに貼るファイル（自動生成）
  preview/*.html    … ブラウザで開いて確認する用（自動生成、ページ間リンクもローカルで動く）
```

ヘッダー・フッター・CSSは全ページで共通です。直したら `python3 site/build.py` を実行し、
**変更のあったページすべて**をWordPressに貼り直してください（共通部分の変更なら全ページ）。

リンク先：お問い合わせフォーム `https://staffpro.jp/`、LINE `https://lin.ee/qeO2S0T`（`build.py` の先頭で一括管理）。

## 錆止めの打ち出し方

一般的な錆止め（錆止め剤を塗って塗装し、塗膜で覆う＝塗装工事の一工程）と、
当社の錆止め（錆そのものを変化させて安定させ、長期的に再発を抑える）を左右に並べて
比較し、塗装とは別に錆止め単体で依頼できることを明記しています。

再発を抑えられる期間（○年など）は、根拠となる資料がないかぎり記載していません。
試験データやメーカー資料があれば、出典とあわせて追記すると説得力が増します。

## 錆止めの価格表示について

「5,500円（税込6,050円）」のように、税込価格を必ず併記しています。消費者向けの
価格表示には消費税の総額表示（税込価格の表示）が義務付けられているためです。
税抜価格を目立たせること自体は問題ありませんが、税込価格を省くことはできません。

## 火災保険まわりの方針

保険金請求のサポートは**消費者庁が注意喚起している分野**です。トラブルの多くは
「必ず保険金が下りる」という説明、成功報酬型の請求代行、そして解約時の違約金に
起因します。同じ土俵に見られないよう、ページは次のスタンスを軸に構成しています。

> 保険金を決めるのは保険会社。私たちの仕事は、正しい証拠を揃えること。

### ページに明記していること

| 項目 | 記載内容 |
| --- | --- |
| 判断主体 | 支払いを判断するのは保険会社。当社は認定を約束しない |
| 証拠のつくり方 | 現地調査／全景・中景・近景の3段階撮影とスケール併記／災害との関連の所見／復旧工事の積算、の4段階を具体的に提示 |
| 申請者 | 保険金請求は契約者の権利のため、申請はお客様のお名前で行う |
| 交渉の代理 | 行わない。不服がある場合はそんぽADRセンター等の公的窓口を案内 |
| 報酬 | 成功報酬なし・違約金なし。いただくのは工事代金のみ |
| 対象外 | 経年劣化・施工不良・故意過失・免責金額未満などを「対象になりにくい例」として明示 |
| 虚偽請求 | 事実と異なる内容の請求には一切関与しない |

### 「代行」という語を使っていない理由

保険金請求そのものは契約者の権利であり、保険会社との交渉を業として代理すると
弁護士法72条に触れうる領域です。「請求代行」を掲げる業者が行政の注意喚起対象に
なっているのもここです。

一方、**調査・被害写真・所見・修理見積書を作成することは建設会社の専門領域**そのもので、
何ら問題ありません。そこで役割を次のように切り分けて記載しています。

- 証拠書類の作成・現地調査への立会い → 当社
- 保険会社への申請 → お客様（ご契約者）
- 支払いの判断 → 保険会社

この切り分けは、法的リスクを避けるためであると同時に、保険会社・鑑定人から見ても
筋の通った相手として扱われるための設計です。「保険会社・鑑定人のみなさまへ」という
ブロックを設け、追加資料の要請に応じる姿勢と、虚偽請求に関与しない方針を明記しています。

## スクロール連動アニメーションについて

フェードイン（`.reveal`）は、**JavaScriptが実際に動いたときだけ**有効になります。
`#crastore-lp` に `.js-on` が付いて初めて要素が透明になり、そこからフェードインします。

これは WordPress のブロックエディタが、カスタムHTMLブロックのプレビュー内で
JavaScript を実行しないためです。`opacity: 0` を初期値にすると、エディタ上で要素が
「見えないまま場所だけ占有」し、大きな空白として表示されます。キャッシュ系プラグインが
スクリプトを遅延・除去した場合も同じ症状が出ます。

初期状態を「見えている」にしておけば、JSが動かない環境でも本文は必ず表示されます。

JSが動く環境では、画面内にすでにある要素を同じフレームで表示状態にしてから
IntersectionObserver を開始するため、一瞬消えるちらつきも起きません。
