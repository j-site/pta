トップページを、**「見やすさ」「頼みやすさ」** を基準に再構成したものです。

1. **火災保険を使った修繕に強い**
2. **他社で断られた・できなかった工事に対応できる**

## 「見やすさ」のための変更

- 本文を15px→**16px**、カード本文を13.5px→**15px**、注釈を13px→14pxに拡大
- 文字色のコントラストをWCAG AA（4.5:1）以上に調整
- 本文の1行あたりの文字数を制限（`max-width: 34em`）
- 長い説明文を、箇条書き・チップ・カードに分解
- ヒーローの抽象的なキャッチを見出しから外し、**何をする会社かを最初の1行**に。
  ブランドのスローガン（皆が表現できないものを、わたしたちが現実にする。）は
  引用として残しています

## 「頼みやすさ」のための変更

- **ハードルの低い相談例を8つ提示**（壁紙の剥がれ、蛇口の水漏れ等）。
  「これくらいで頼んでいいのか」という迷いを消すのが狙いです
- CTAの文言を「無料で相談する」→**「写真を送って無料見積り」**（次の行動が具体的）
- ボタンのすぐ下に**不安を消す一言**（相談・見積り無料／断ってOK／しつこい営業なし）
- **PCヘッダーに電話番号を常設**
- **スマホは画面下に「電話」「フォーム」を常時表示**（従来はハンバーガーを開かないとCTAに到達できなかった）
- 「費用について」セクションを新設
- よくあるご質問を新設（保険・断られた工事・見積りの断り方など7問）

## 書体について

| 用途 | 書体 |
| --- | --- |
| 大見出し（h1・セクション見出し） | Shippori Mincho B1（しっぽり明朝B1） |
| 本文・小見出し | Zen Kaku Gothic New |
| 英数字（電話番号・番号・ラベル） | Archivo |

当初の Noto Sans JP + Montserrat は、テンプレートや自動生成のサイトで最も多用される
組み合わせのため変更しました。見出しに明朝体を使うことで、同業他社のサイトとの差別化と
「職人・確かさ」の印象を狙っています。本文は可読性を優先してゴシックのままです。

書体を差し替える場合は、次の2箇所だけを変更してください。

1. ファイル冒頭の `<link href="https://fonts.googleapis.com/css2?family=...">`
2. CSS内の `--font-head` / `--font-jp` / `--font-en` の3行

## 火災保険まわりの表現について

保険金請求のサポートは**消費者庁が注意喚起している分野**です。トラブルの多くは
「必ず保険金が下りる」という説明と、成功報酬型の請求代行に起因します。
そのため本ページでは次の方針を取っています。

- 「必ず下りる」と読める表現は使わない（支払いを判断するのは保険会社である旨を明記）
- 経年劣化は対象外であることを明記
- 事実と異なる申請には関与しない旨を明記
- 保険金の一部を成功報酬として受け取らない／請求代行業者ではないことを明記

これは法的リスクを避けるためであると同時に、悪質な業者との違いを示す
差別化ポイントとしても機能します。

## Instagram

会社概要・フッターに設置しています。

ご提供いただいたURLに付いていた `stkn=` は個人の共有トークンのため、

印刷物にはQRをそのままお使いください。
