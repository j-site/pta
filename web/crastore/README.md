# 株式会社Crastore ホームページ 修正版

現行サイト（https://crastore.xyz/ ・WordPressの「カスタムHTML」ブロックに貼り付けて運用）の
HTMLをベースに、不具合の修正とアクセシビリティ／SEOの改善を行ったものです。

## ファイル

| ファイル | 用途 |
| --- | --- |
| `wp-home.html` | **WordPressに貼り付ける本体。** 固定ページの「カスタムHTML」ブロックに丸ごと貼り付けて公開し、設定→表示設定でホームページに指定します。 |
| `preview.html` | ローカルで表示確認するためのラッパー。ブラウザで直接開けます（WordPressには貼り付けません）。 |

デザイン・文章・配色・リンク先（Googleフォーム、電話番号）は現行のまま変更していません。

## 修正した内容

### 不具合

1. **アンカーリンクで見出しが固定ヘッダーに隠れる**
   `#service` などへ移動すると、高さ64pxの固定ヘッダーの下にセクション見出しが潜り込んでいました。
   各セクションに `scroll-margin-top` を指定して解消。
2. **スマホでヘッダーのCTAボタンが消える**
   880px以下ではナビ全体が `display:none` になるため、ハンバーガーを開かない限り
   「無料相談はこちら」に到達できませんでした。画面下部に追従する問い合わせボタンを追加。
3. **`<meta charset="utf-8">` が本文中にあった**
   `<body>` 内の meta タグはブラウザに無視されます（WordPressが `<head>` で出力済み）。削除。
4. **JavaScriptが無効だと本文が真っ白になる**
   `.reveal` は初期状態が `opacity:0` で、表示はJSに依存していました。
   `<noscript>` で強制表示するスタイルを追加。
5. **メニュー内リンクの子要素をタップしてもメニューが閉じない**
   `e.target.tagName === 'A'` の判定を `closest('a')` に変更。
6. **メニューが閉じる手段が足りない**
   メニュー外のクリック・Escキー・画面幅を広げた時にも閉じるよう追加。
7. **HTMLに存在しない `.svc .arrow` 用のCSSが残っていた** — デッドコードのため削除。
8. **会社概要の表が狭い画面ではみ出す可能性**
   横スクロールできるコンテナで包み、`<tbody>` と `scope="row"` を補完。
9. **著作権表記の年が固定値（2026）**
   毎年の書き換えが必要だったため、JavaScriptで自動更新。
10. **スマホのメニューが縦に長いと画面外に出る**
    `max-height` + `overflow-y:auto` を指定。

### アクセシビリティ

- 文字色のコントラスト不足を解消（`--muted` `#6b7280` → `#5f6773`、白背景に置く
  オレンジ文字は `#f08300` → `#b35d00`）。いずれもWCAG AAの4.5:1を満たします。
- ハンバーガーボタンに `aria-expanded` / `aria-controls` を追加し、開閉状態とラベルを切り替え。
- キーボード操作時のフォーカスリングを明示（テーマ側で `outline:none` されていても効くよう指定）。
- 装飾用の絵文字・記号に `aria-hidden="true"` を付与（読み上げのノイズを削減）。
- 別ウィンドウで開くリンクにその旨のテキストを追加（視覚的には非表示）。
- 各セクションに `aria-labelledby` を付与。
- `prefers-reduced-motion`（動きを減らす設定）に対応。

### SEO

- 構造化データ（JSON-LD / `GeneralContractor`）を追加。会社名・住所・電話番号・営業時間・
  対応エリアを検索エンジンに明示します。

## 表示確認

Chromium（1440×900 / 390×844）で確認済み。横スクロールの発生なし、JavaScriptエラーなし。

## 補足

- 現行サイトのHTMLはご提供いただいたコードを元にしています（このセッションからは
  crastore.xyz / crastore.jp へネットワーク接続できないため、実サイトの取得は未実施）。
- ページの `<title>` とメタディスクリプションはWordPress側の設定項目のため、このHTMLからは
  変更できません。SEO上重要なので、固定ページの設定またはSEOプラグインでの設定を推奨します。
- セクションのID（`#service` `#company` `#contact` など）がテーマ側のIDと重複する場合は
  リンクの飛び先がずれることがあります。現状のテーマでは重複を確認していませんが、
  テーマ変更時はご注意ください。
