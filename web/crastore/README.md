### 錆止めの打ち出し方

一般的な錆止め（錆止め剤を塗って塗装し、塗膜で覆う＝塗装工事の一工程）と、
当社の錆止め（錆そのものを変化させて安定させ、長期的に再発を抑える）を左右に並べて
比較し、塗装とは別に錆止め単体で依頼できることを明記しています。

再発を抑えられる期間（○年など）は、根拠となる資料がないかぎり記載していません。
試験データやメーカー資料があれば、出典とあわせて追記すると説得力が増します。

### 錆止めの価格表示について

「5,500円（税込6,050円）」のように、税込価格を必ず併記しています。消費者向けの
価格表示には消費税の総額表示（税込価格の表示）が義務付けられているためです。
税抜価格を目立たせること自体は問題ありませんが、税込価格を省くことはできません。

## 火災保険まわりの方針

保険金請求のサポートは**消費者庁が注意喚起している分野**です。トラブルの多くは
「必ず保険金が下りる」という説明、成功報酬型の請求代行、そして解約時の違約金に
起因します。同じ土俵に見られないよう、ページは次のスタンスを軸に構成しています。

> 保険金を決めるのは保険会社。私たちの仕事は、正しい証拠を揃えること。

### ページに明記していること

| 項目 | 記載内容 |
| --- | --- |
| 判断主体 | 支払いを判断するのは保険会社。当社は認定を約束しない |
| 証拠のつくり方 | 現地調査／全景・中景・近景の3段階撮影とスケール併記／災害との関連の所見／復旧工事の積算、の4段階を具体的に提示 |
| 申請者 | 保険金請求は契約者の権利のため、申請はお客様のお名前で行う |
| 交渉の代理 | 行わない。不服がある場合はそんぽADRセンター等の公的窓口を案内 |
| 報酬 | 成功報酬なし・違約金なし。いただくのは工事代金のみ |
| 対象外 | 経年劣化・施工不良・故意過失・免責金額未満などを「対象になりにくい例」として明示 |
| 虚偽請求 | 事実と異なる内容の請求には一切関与しない |

### 「代行」という語を使っていない理由

保険金請求そのものは契約者の権利であり、保険会社との交渉を業として代理すると
弁護士法72条に触れうる領域です。「請求代行」を掲げる業者が行政の注意喚起対象に
なっているのもここです。

一方、**調査・被害写真・所見・修理見積書を作成することは建設会社の専門領域**そのもので、
何ら問題ありません。そこで役割を次のように切り分けて記載しています。

- 証拠書類の作成・現地調査への立会い → 当社
- 保険会社への申請 → お客様（ご契約者）
- 支払いの判断 → 保険会社

この切り分けは、法的リスクを避けるためであると同時に、保険会社・鑑定人から見ても
筋の通った相手として扱われるための設計です。「保険会社・鑑定人のみなさまへ」という
ブロックを設け、追加資料の要請に応じる姿勢と、虚偽請求に関与しない方針を明記しています。

## スクロール連動アニメーションについて

フェードイン（`.reveal`）は、**JavaScriptが実際に動いたときだけ**有効になります。
`#crastore-lp` に `.js-on` が付いて初めて要素が透明になり、そこからフェードインします。

これは WordPress のブロックエディタが、カスタムHTMLブロックのプレビュー内で
JavaScript を実行しないためです。`opacity: 0` を初期値にすると、エディタ上で要素が
「見えないまま場所だけ占有」し、大きな空白として表示されます。キャッシュ系プラグインが
スクリプトを遅延・除去した場合も同じ症状が出ます。

初期状態を「見えている」にしておけば、JSが動かない環境でも本文は必ず表示されます。

JSが動く環境では、画面内にすでにある要素を同じフレームで表示状態にしてから
IntersectionObserver を開始するため、一瞬消えるちらつきも起きません。

## 「船の内装工事」での検索対策

上位の会社（JOYSIS、大船装飾、山陽ワークス、HIJIYA など）は、いずれも船舶内装の専門ページを
持っています。4事業を並べたトップページの1セクションでは比較の土俵に乗れないため、
専用ページ `wp-ship-interior.html` を用意しました。

- タイトル・見出し・本文に「船の内装工事」「船室のリフォーム」を自然に含める
- 対応工事、船ならではの配慮（湿気・塩分／揺れ／狭い搬入口／曲面／内装材の基準）、流れ、Q&A を掲載
- 施工事例のひな形（コメントアウト中）。写真付きの事例が最も効果があります
- 構造化データ（Service、BreadcrumbList）
- トップページの船舶カード・船舶セクション・フッターから専用ページへリンク

WordPress 側で設定が必要なもの（HTMLからは変更できません）:
- ページタイトル: 船の内装工事・船室リフォーム｜大阪の株式会社Crastore
- メタディスクリプション: 船の内装工事・船室のリフォームなら大阪の株式会社Crastore。床・壁・天井の張り替え、収納の取り付け、部分補修から船の外部の工事まで。湿気・揺れ・狭い空間など船ならではの条件に合わせて施工します。写真1枚から無料でお見積り。
