  • 原状回復
  • 壁・床・建具の部分補修
  • 店舗の内装
  • 台風・雨漏りなどの災害修繕

「うちでは無理です」と言われた工事も。

断られた理由の多くは、工事が不可能だからではなく、その会社の体制に合わなかっただけです。当社でも難しい場合は、その理由を正直にお伝えします。

  • 「規模が小さくて受けられない」一箇所だけでも対応します壁のキズ、建具の建て付け、蛇口の交換。小さな工事こそお引き受けします。
  • 「工種がまたがるので無理」多工種をワンストップで解体から仕上げまで、業者を探し回っていただく必要はありません。
  • 「保険が絡む工事は扱わない」証拠書類から対応します被害の調査、申請に必要な写真・所見・見積書の作成、認定後の施工まで。

Insurance

保険金を決めるのは、保険会社です。
私たちの仕事は、正しい証拠を揃えること。

台風・大雨・雪・落雷・飛来物などによる建物の破損は、契約内容によって火災保険の対象になります。対象かどうかを判断するのは保険会社です。だからこそ、被害の事実を第三者が見て判断できる証拠と書類にすることが大切です。

  • 判断するのは、保険会社「必ず下ります」とは申し上げません。対象になりそうかどうかを、根拠とあわせて正直にご報告します。
  • 事実に基づく書類だけを作る経年劣化を災害として記載しません。災害起因と判断できる部分とそうでない部分を分けて明記します。
  • 成功報酬はいただかないいただくのは工事代金だけです。認定額で報酬が増える仕組みではないため、過大な請求をする動機がありません。
証拠書類のつくり方と、申請までの流れ

証拠書類のつくり方

  1. 現地調査で被害箇所を特定する屋根・外壁・雨樋・付帯設備まで確認し、どこがどう壊れているかを記録します。
  2. 全景・中景・近景の3段階で撮影するスケールを当てて寸法が読めるように撮影し、撮影日を残します。
  3. 災害との関連を所見として書く破損の形状・方向・範囲から原因を根拠とともに記載。断定できない箇所は、断定できないと書きます。
  4. 復旧に必要な工事を積算する範囲・数量・単価を明示した修理見積書。施工する会社の見積書なので、金額に裏付けがあります。

申請までの流れ

  1. ご相談・現地調査（無料）
  2. 調査結果のご報告対象になりそうか、根拠とあわせてお伝えします。
  3. 書類一式をお渡し被害写真・所見・修理見積書。
  4. お客様のお名前で保険会社へ申請保険金請求はご契約者の権利のため、申請者はお客様です。書き方はご説明します。
  5. 鑑定人の現地調査に立会い
  6. 認定内容に沿って施工認定されなかった場合、工事を無理にお勧めしません。
対象になりうる例・なりにくい例
  • 屋根瓦のズレ・破損
  • 雨樋の破損・変形
  • 外壁のひび・剥がれ
  • 雨漏り
  • 窓ガラス・網戸
  • カーポート・テラス屋根
  • フェンス・門扉
  • アンテナの倒れ
  • 経年劣化による傷み
  • 施工不良が原因のもの
  • 故意・過失による破損
  • 免責金額に満たない被害
  • 災害との関連が確認できないもの

数年前の台風による被害でも申請できる場合があります（一般に保険法上の請求権の時効は3年。契約内容により異なります）。

保険会社・鑑定人のみなさまへ

当社は、被害の事実を正確に記録し、復旧に必要な工事を過不足なく積算することを方針としています。現地調査には立会い、施工者の立場から技術的な根拠をご説明します。追加資料や撮り直しのご要請にも対応し、事実と異なる内容での請求には一切関与しません。

当社が行わないこと

保険金請求の代行は行いません。申請はご契約者であるお客様のお名前で行っていただき、当社は調査・書類作成・現地調査への立会いを担います。

保険会社との交渉の代理は行いません。認定内容にご不満がある場合は、保険会社の相談窓口や、そんぽADRセンター（一般社団法人 日本損害保険協会）などの公的な窓口をご案内します。

成功報酬として保険金の一部をいただくこと、解約時に違約金を請求すること、事実と異なる内容での請求に関与することは、いずれもいたしません。

03 Rust Proofing

錆は、広がる前に止める。

鉄は一度錆びはじめると、表面から内側へと進行します。放置すれば強度が落ち、部材ごとの交換や大がかりな補修が必要になります。早めの錆止めが、いちばんの節約です。

錆止め施工

5,500円／㎡

税込 6,050円／㎡

錆の進行度合い、足場の要否、施工面積によって別途費用が発生する場合があります。現地を確認のうえ、正式なお見積りをお出しします。

施工の流れ

  1. 写真の送付・現地確認錆の範囲と進行度合いを確認します。
  2. お見積り面積と作業内容を明示します。ここまで無料です。
  3. 下地処理錆や劣化した旧塗膜を落とし、塗料が密着する面をつくります。
  4. 錆止め塗装
  5. 仕上がりの確認・お引き渡し

こんな箇所に

  • 鉄骨階段
  • 手すり・ベランダ
  • 鉄扉・門扉
  • フェンス
  • トタン・折板屋根
  • 鉄骨の柱・梁
  • 設備架台・看板支柱
  • 船舶の鋼材部

Q&A

よくあるご質問

錆止めの5,500円／㎡には、何が含まれますか？
錆止め施工の平米単価です（税別。税込6,050円）。錆の進行度合いや足場の要否、施工面積によって別途費用が発生する場合があるため、現地を確認したうえで、作業内容を明示した正式なお見積りをお出しします。お見積りまでは無料です。
他社に断られた工事でも、相談していいのですか？
はい。断られた理由を教えていただければ、当社で対応できるかどうかを判断してお伝えします。当社でも難しい場合は、その理由をはっきりお伝えします。
火災保険は、本当に使えるのでしょうか？
自然災害による破損であれば、契約内容によって対象になる可能性があります。ただし支払いを判断するのは保険会社で、当社がお約束することはできません。調査のうえ、対象になりそうかどうかを根拠とあわせて正直にお伝えします。経年劣化は原則として対象外です。
保険の申請は自分でやるのですか？
保険金の請求はご契約者ご本人の権利のため、申請はお客様のお名前で行っていただきます。当社は現地調査・被害写真・所見・修理見積書の作成と、鑑定人の現地調査への立会いを担当します。書き方はご説明しますので、ご負担は書類を保険会社へ送っていただく程度です。保険会社との交渉の代理はいたしません。
見積りだけでも大丈夫ですか？
大丈夫です。ご相談・現地調査・お見積りまで無料です。金額を見てお断りいただいて構いませんし、しつこい営業もいたしません。
対応エリアはどこまでですか？
大阪府を中心に対応しています。エリア外かどうか迷われる場合も、まずはお問い合わせください。
